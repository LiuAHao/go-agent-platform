# 前端组件模块说明

`web/console/src/components` 负责公共 Agent 平台的页面组件、控制台主工作区和共享展示组件。

## 当前设计目标

这一版前端以“零基础用户也能直接装配 Agent”为主要目标，页面设计遵循两条规则：

- 首屏只保留必要字段，避免用户一上来面对大量专业参数。
- 高级能力统一收纳到“高级设置”折叠区，保留扩展性，但不干扰基础使用。

## 主要组件职责

### `LandingPage.tsx`

平台公开首页。负责展示平台定位、能力装配流程，以及登录 / 注册入口。

### `AuthPage.tsx`

登录页与注册页外壳。当前后端已接入登录，注册页保留前端入口与跳转路径。

### `Sidebar.tsx`

控制台左侧导航，负责：

- 主功能入口切换
- Agent 列表展示
- 侧栏收起 / 展开
- 系统设置与退出登录入口

### `AgentDashboard.tsx`

控制台核心页面容器，负责切换并渲染以下页面：

- 新建 Agent
- Agent 聊天页
- 技能与应用
- MCP 配置
- 模型配置
- 系统设置

## 当前页面约定

### 新建 Agent

为了降低理解成本，`Agent 描述` 和 `System Prompt` 已合并为一个字段：

- 页面上只展示 `Agent 说明`
- 提交时同时写入后端的 `description` 和 `system_prompt`

用户只需要完成：

- Agent 名称
- Agent 说明
- 模型选择
- Skill / MCP 勾选装配

### MCP 配置

MCP 创建页默认只展示：

- 名称
- 描述
- 绑定 JSON

以下内容被收纳到 `高级设置`：

- 发布范围
- 调用审批
- Schema JSON

### 技能与应用

Skill 页面分为 `平台 Skill` 和 `我的 Skill`。

其中个人 Skill 创建模式分为两种：

- 本地上传文件夹
- AI 生成 Skill

当前前端只对基础字段做直接暴露：

- 名称
- Slug
- 描述

其中：

- 本地上传模式支持读取文件夹内容并随 Skill 一起保存为草稿配置
- 已创建的个人 Skill 支持下载草稿 JSON，便于继续本地修改
- AI 生成入口已保留在界面中，等待后端生成接口接入

高级设置中保留：

- 版本
- 入口标识

### 模型配置

模型创建页默认只保留最少接入字段：

- 模型名称
- 官方模型名称
- API URL
- API Key

以下字段被放入 `高级设置`：

- Provider
- 描述
- 上下文窗口
- 最大输出 Token
- 默认模型

## 路由与跳转逻辑

当前前端使用轻量路径映射：

- `/`：平台首页
- `/login`：登录页
- `/register`：注册页
- `/app`：登录后的控制台

跳转规则：

- 未登录访问 `/app` 时自动跳转到 `/login`
- 登录成功后进入 `/app`
- 退出登录后回到 `/`

## 共享组件

### `AppIcon.tsx`

统一维护侧边栏、页面头图标和公共功能图标，避免同一功能出现多套图标风格。

## 后续建议

如果后端继续补齐能力，前端下一步建议优先接入：

1. 个人 Skill 的替换上传与更新接口
2. AI 生成 Skill 的真实后端接口
3. MCP 连接测试与连通性校验接口
4. 模型配置校验与连通性测试
